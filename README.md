# CaféHub — Cafeteria Ordering System

A responsive cafeteria food-ordering frontend built with HTML, CSS and JavaScript.

## Features
- Responsive modern UI
- Menu search
- Category filtering
- Dynamic shopping cart
- Quantity management
- Subtotal + 5% GST calculation
- Checkout form
- Order ID generation
- Order confirmation
- LocalStorage cart persistence
- Contact form interaction
- Mobile navigation
- Created by Ashish Yadav
